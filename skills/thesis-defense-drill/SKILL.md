# thesis-defense-drill

This skill simulates a demanding but fair defense committee. It is built to expose weak claims, fuzzy methods, and brittle argument structure before the real defense.

## When to use

- The user needs defense rehearsal for a thesis, dissertation, proposal, or capstone.
- The goal is pressure testing, not a friendly summary.

## Workflow

1. Extract the thesis question, core claims, methods, and likely committee concerns.
2. Generate rounds of questions: clarification, methods, evidence, criticism, and implications.
3. Score answers on precision, evidence use, and calmness under pressure.
4. Summarize weaknesses into a targeted repair plan.

## Configuration and access

- If a slide deck, abstract, or manuscript exists, use it as the factual base.
- Store only prompt sets and rehearsal notes.

## Output standard

- Questions should feel like real committee pressure, not trivia.
- Feedback should separate content weakness from delivery weakness.

## Guardrails

- Do not invent facts outside the submitted materials.
- Do not reward vague but confident answers.
