# Windows First Routing

Default to Windows when:

- the canonical `.codex` store lives on Windows
- VS Code should not depend on WSL startup health
- Linux tools are available through separate commands or agents

Verify user settings, extension-specific executable overrides, and `CODEX_HOME` alignment together.
