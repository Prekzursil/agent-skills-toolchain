# BinDiff Notes

## Upstream

- Project: https://github.com/google/bindiff

## Local install

- Installed binary path: `C:\Program Files\BinDiff\bin\bindiff.exe`
- Helper binary also available there: `binexport2dump.exe`

## Rule of use

Use `$binexport` first. BinDiff should operate on exporter output from both sides, not on raw assumptions about the original projects.
