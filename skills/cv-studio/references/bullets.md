# Writing bullets that land (XYZ · STAR · CAR · Brag-Document)

Every bullet is drawn from `x_master` and cites numbers only from `x_metrics`. Turn a long-form
achievement note into a punchy, quantified line with one of these formulas.

## The Google XYZ formula (default)
> **Accomplished [X], measured by [Y], by doing [Z].**

- "Reverse-engineered a proprietary save format (**X**), shipping an editor used by 12,000+
  players (**Y**), by documenting the header/checksum layout in Ghidra (**Z**)."
- Start with a strong past-tense **action verb**. Put the **result/metric early** — recruiters
  skim the first few words of each bullet.

## STAR (behavioural / interview parity)
**S**ituation → **T**ask → **A**ction → **R**esult. Good for cover letters and interview stories;
compress to the Action + Result for a CV bullet.

## CAR (concise variant)
**C**hallenge → **A**ction → **R**esult. Use when the situation is obvious from the role.

## Brag-Document discipline (the content upstream of any tool)
Keep a running log of *what you did + why it mattered + the measurable result* (Julia Evans,
jvns.ca/blog/brag-documents). That log **is** your `x_master`. "Reverse-engineered X" becomes
"Reverse-engineered the save format, shipping a tool used by N players" — the second is hireable,
the first is a task. The metric is what converts effort into evidence.

## Action-verb bank (rotate; avoid "responsible for")
- **Built/Shipped:** Built, Shipped, Engineered, Developed, Implemented, Architected, Automated,
  Designed, Prototyped, Deployed, Released.
- **Improved:** Optimised, Reduced, Cut, Accelerated, Scaled, Streamlined, Hardened, Refactored.
- **Analysed (RE/security):** Reverse-engineered, Decompiled, Disassembled, Instrumented,
  Emulated, Fuzzed, Triaged, Recovered, Bypassed, Hooked, Patched.
- **Led:** Led, Drove, Coordinated, Mentored, Owned, Founded.

## Quantify — even when you think you can't
Time saved, % faster, count of users/downloads/stars, $ or scale, error/crash reduction, team
size, number of systems. If a real number exists, it goes in `x_metrics` and then the bullet.
No inventing — an unverifiable number is worse than none.

## Anti-patterns
- Passive voice / "responsible for" / "duties included".
- Adjective soup with no metric ("excellent communicator", "hard worker").
- Tool lists masquerading as achievements (put tools in the Skills block).
- The same verb five times — rotate the bank above.
