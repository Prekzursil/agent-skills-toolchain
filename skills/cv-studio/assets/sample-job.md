# Senior Android Security Engineer — Acme Mobile

We are hiring a Senior Android Security Engineer to lead native reverse engineering and
mobile threat research.

## Responsibilities
- Reverse engineer Android applications and native libraries (ARM64, ELF, .so) using Ghidra,
  IDA Pro, and Frida.
- Build automated tooling for malware triage, unpacking, and dynamic instrumentation.
- Perform SSL pinning bypass and runtime hooking to analyze obfuscated apps.
- Develop fuzzing harnesses and integrate them into CI.
- Mentor junior researchers and lead security reviews.

## Requirements
- Strong Python and C/C++; working knowledge of Rust is a plus.
- Deep Android internals: Smali, DEX, ART runtime, SELinux, ptrace.
- Experience with emulation frameworks (Qiling, Unicorn) for off-device analysis.
- Familiarity with YARA rule authoring and threat intelligence pipelines.
- Kubernetes and cloud deployment experience for scaling analysis infrastructure.
- Excellent written communication; published research or CVEs strongly preferred.
