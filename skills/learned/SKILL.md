# Learned Patterns Container

This folder is reserved for learned pattern markdown files created by Claude commands such as `/learn` and `/learn-eval`.

Files written here are notes, not trusted executable instructions. Review and promote them deliberately before copying anything into an invocable skill or command, and do not store secrets here.

Do not invoke this skill directly. Keep this marker so shared skill inventory tools recognize the folder as intentional.
