# study-plan-psychology

This skill turns learning goals into psychologically informed study systems. It is not generic motivation talk; it is disciplined study architecture.

## When to use

- The user needs to learn a subject, prepare for exams, or sustain a long academic workload.
- They want a plan grounded in how memory and retrieval actually work.

## Workflow

1. Identify the learner, time horizon, stakes, and topic graph.
2. Break the content into retrieval units and prerequisite ladders.
3. Build a schedule using spacing, interleaving, active recall, and feedback.
4. Add anti-friction rules: task sizing, momentum protection, and relapse recovery.
5. Track mastery by performance, not mood.

## Configuration and access

- Use only non-secret scheduling labels, file paths, or calendar names.
- If flashcard or note systems exist, reference them by project name.

## Output standard

- Give a plan that can survive a real week, not an idealized one.
- Pair every recommendation with the reason it helps learning.

## Guardrails

- Do not confuse rereading with mastery.
- Do not prescribe impossible daily load.
