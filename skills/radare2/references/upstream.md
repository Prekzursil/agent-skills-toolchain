# Upstream Notes

- Official site: `https://rada.re/n/`
- If `r2` is already on PATH, start with `r2 -A <binary>` and verify with `r2 -v`
- High-signal starter commands:
  - `aaa` - deeper analysis
  - `afl` - list functions
  - `pdf` - disassemble current function
  - `iz` - strings
  - `ii` - imports
- Prefer exact command transcripts over memory when sharing findings with another agent
