# WHY THIS EXISTS
#   ~/.claude is 14.218 GB and is NOT a git repo (verified: `git -C ~/.claude rev-parse
#   --is-inside-work-tree` -> "fatal: not a git repository"). Committing 14 GB is not the answer.

# SYNTAX
#   Lines are, in order of precedence:
#     !<glob>   HARD DENY - never copied, even if an include matches. Evaluated first.
#     <glob>    INCLUDE - copied when no deny matches.
#   Globs are matched against the path RELATIVE to ~/.claude, using forward slashes.
#   '**' matches across directory separators. Blank lines and '#' comments are ignored.
#
# ---------------------------------------------------------------------------------------------
# HARD DENY - credentials and secrets. NEVER copy these into a repo with a remote.
# ---------------------------------------------------------------------------------------------
# ~/.claude/.credentials.json is 30,292 B of live OAuth material. The estate policy permits
# reading credentials locally, but the boundary is EGRESS, and ~/.agents has a GitHub remote.
# ~/.agents/.gitignore already ignores '*credential*' and '*token*.json', so git would refuse
# it anyway - this deny is the belt to that braces, not a substitute for it.
#
# CORRECTED 2026-09-25: the first version of this block used '!**/*credential*', a SUBSTRING
# match on the path. That silently dropped four authored source files -
#   hooks/deny-credential-reads/{deny.py,test_deny.py,test_denylist_coverage.py,test_guard_scope.py}
# - i.e. the source of the hook that GUARDS credential reads, because its DIRECTORY name
# contains the word. A baseline that quietly omits the credential guard is worse than no
# baseline. The denies below are anchored to the FILE NAME, and the script's CRED gate
