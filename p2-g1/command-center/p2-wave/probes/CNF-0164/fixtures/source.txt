# Load policy (planted source for CNF-0164 quote-fidelity controls).
A file absent from MANIFEST.json is not loaded, even if it sits in a capabilities directory.
Quoted documentation must byte-match the source at the cited revision.
EOL differences are not meaning differences; a copy-pasted quote is exact.
The loader reads only listed paths:
capabilities/alpha.json
capabilities/beta.json
Only MANIFEST-listed capabilities are mounted at boot.
