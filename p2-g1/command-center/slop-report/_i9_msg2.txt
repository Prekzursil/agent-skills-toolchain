THE CONTESTED RESIDUAL, SETTLED. An adversarial round called _r4_buckets.py's C5 an inert
control and blocking. Rounds 5 through 7 never closed it and it was still in the committed
bytes when I arrived. I did not take the refutation on trust -- I re-derived it. The shipped
form reads sorted(X) == sorted(<the expression that produced X>), and evaluated under three
scan implementations it is TRUE IN ALL THREE: real, returns-nothing, fabricates-a-constant.
The adversary was right. It sat in the PASS conjunction as the only control over S1, the
signal the classifier calls its strongest. C3 was refuted the same way: it tested set
membership beside sibling_producer instead of calling it, and was not in PASS at all.

Both replaced. C5 is now a mutation pair -- perturb the scan's input, require its output to
move: with nothing tracked the finding set must grow, with every target tracked it must
empty. Neither broken state satisfies both. C3 now calls the real function on a real tracked
pair and demands a runnable command back. Verdict C5-FIX-PROVEN, 5 of 5, with a P0
self-control asserting the comparator can produce both booleans, because a probe that
reports false everywhere looks exactly like a successful refutation.

The receipt was NOT regenerated, deliberately. _r4_buckets.out.json belongs to rounds 4 and 5
and sibling documents publish numbers from it -- including to the gate wired this round. So
the edited classifier was executed end to end in a fresh CLONE, where its receipt costs
nothing, and the source receipt was verified byte-and-mtime identical afterwards. The clone's
receipt carries the new control keys, which is what proves the edited file actually ran.
