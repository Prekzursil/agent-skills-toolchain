command-center/casualty/_probe_liveness.py:97 writes to OUT/"ADV-LIVENESS.json" and _probe_census.py:161 writes to OUT/"ADV-COMPLETENESS-CENSUS.json" — the exact two files the builder stamped with _SUPERSEDED_BY / _DO_NOT_CITE. Fix: `raise SystemExit("SUPERSEDED by liveness_v2.py")` at the top, or redirect the output path.

D2 (MEDIUM) — verify_elided_digest.py fails OPEN on empty input.
`$ python command-center/casualty/verify_elided_digest.py` (no arguments) prints NOTHING and exits 0. Its loop is `for path in sys.argv[1:]` with no arity check, so a zero-input invocation is indistinguishable from two passing verifications. This is precisely the ci-hygiene "empty walk must fail closed" shape, in a tool whose entire purpose is anti-fabrication verification. The right pattern is in the same directory: census_v2.py runs its control first and exits non-zero WITHOUT printing a tally. Fix: `if not sys.argv[1:]: print("FAILED:elided-digest no inputs"); sys.exit(1)`.

D3 (MEDIUM) — liveness_v2.py's three-state control is opt-in, so the citable tally is produced without it.
The selftest is gated behind `--selftest` (liveness_v2.py:163-167); the default run that emits "verdict tally: {'SUBSTANTIVE': 38, 'RECOVERED': 2}" never exercises it. A gate reporting ZERO casualties is exactly the case where the fire-check must run every time. It does pass when invoked — I ran it, all three states PASS — so this is a wiring defect, not a broken control. Fix: run selftest() unconditionally before evaluate(), mirroring census_v2.py.

D4 (LOW) — probes/adv0022_git_verifier.sh:31 hardcodes a narrative number that has drifted.
Line 31 prints the literal string "a raw count matched 219 files, of which 12 were this lane's own artifacts", immediately above lines 33/34 which COMPUTE raw_including_this_lane=225 and repo_wide=208 (a 17-file lane delta, not 12). The probe's own output now self-contradicts. The load-bearing figures (208 and 8, and the git_grep_exit=1 zero against the 289-file empty-pathspec control) are recomputed live and reproduce exactly, so no conclusion moves. Fix: compute the delta instead of narrating it.
