  --- live 135-167 (33 lines) under ## 7. One-level nesting + a schema on EVERY fan-in
      | - **Schema on every fan-in — but ARTIFACT-FIRST, and keep the schema SMALL.**
      |   Every `agent()` that feeds an aggregation carries a `schema`, so you aggregate
      |   typed objects instead of re-parsing prose. But the schema must be a *pointer*,
      |   not the deliverable (see the artifact-first rule below).
      |   **Do NOT set `additionalProperties: false` on a fan-in schema.** It converts a
      |   cosmetic extra key into a hard, unrecoverable rejection, and it is the
      |   difference between "one stray field ignored" and "5 retries burned, work lost".
      |   Reserve it for tiny gate verdicts you fully control.
      | - **THE `{"raw": …}` DOUBLE-ENCODE FAILURE — observed 2026-07-23 (`wf_950ea2e9-e82`).**
      |   A lens with 35 tool calls and genuinely good findings emitted
      |   `StructuredOutput({"raw": "{\"lens\":\"…"})` — the whole object JSON-encoded
      |   into a single string field — five times, identically, then died:
      |   `StructuredOutput retry cap (5) exceeded — 5 failed calls with no valid output`.
      |   This is a DIFFERENT mechanism from the over-broad-`required` case below: the
      |   model had all the data and simply serialised it one level too deep. Because
      |   `additionalProperties: false` + 6 `required` fields rejected `raw` outright, the
      |   retry surfaced no partial credit and the agent never self-corrected.
      |   Mitigations, in order of proven value:
      |   1. **Artifact-first** (below) — makes the failure survivable at all.
      |   2. Omit `additionalProperties: false`; keep `required` ≤ 4; drop `minItems`.
      |   3. Keep every schema **flat** — no arrays-of-objects in a fan-in schema; long
      |      prose belongs in the artifact, not in a string field.
      |   4. Say it explicitly in the prompt: *"Return the object directly; never wrap it
      |      in a `raw` key; never place JSON inside a string field."*
      |   5. Last resort: `try { await agent(p,{schema}) } catch { await agent(p) }` and
      |      parse the text — a schemaless retry cannot hit the cap.
      | - **ARTIFACT-FIRST IS THE PRIMARY CONTRACT (fan-out-contract C1), not a
      |   belt-and-braces extra.** Any agent whose output matters MUST write its full
      |   deliverable to a pinned path as its FIRST action (skeleton with every section
      |   marked `UNKNOWN - not yet measured`), rewrite it at each milestone, and return
      |   only `{ok, path, headline}`. Then a schema rejection costs a pointer, never the
      |   work. Measured cost of ignoring this: 57 minutes of a 10-lens audit wave
      |   discarded on a serialisation shape (`wf_950ea2e9-e82`, 2026-07-23).
      REPO REPLACES IT WITH (5 lines):
      > - **Schema on every fan-in.** Every `agent()` that feeds an aggregation MUST
      >   carry a `schema` (with `additionalProperties: false` and an explicit
      >   `required`). You then aggregate typed objects, never re-parse prose. The
      >   aggregator agent also takes a schema. This is what makes the gates
      >   "schema-typed": `{ verdict, blocking, ... }` on each reviewer.
