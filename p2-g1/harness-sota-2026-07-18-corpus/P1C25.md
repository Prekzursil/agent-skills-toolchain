# P1C25 — Normalized audit findings from D17–D20

## Scope and method

This unit normalizes the 35 explicitly numbered findings in `D17.md`, `D18.md`, `D19.md`, and `D20.md`. Stable IDs are the source document ID plus its finding number. “Claimed severity” is normalized from the source's `value x effort` field (`high` or `med` value); these source files do not provide a separate defect-severity scale. `SUPPORTED`, `PARTIAL`, and `UNSUPPORTED` assess only internal entailment: whether the cited evidence, accepted at face value, supports the finding's claim. The underlying paths, command outputs, and URLs are **UNVERIFIED** in this unit; opening/rerunning every cited path/command and checking the cited web pages is the later experiment that settles external truth.

The architecture column applies the required proposal classification. Where a source does not give an implementation size, `BUILD-SMALL` is an **UNVERIFIED** classification; a line-counted implementation design is the experiment that would distinguish it from `BUILD-LARGE`. No record proposes a second orchestration runtime, vector/KG memory, durable-execution engine, trained critic, observability SaaS, or guardrail framework.

Judgment confidence is **almost certain (90-99%)** for the transcription and internal-coherence labels because each record was derived directly from the source finding's `what`, `evidence`, and `value x effort` fields; this does not increase confidence that the cited evidence is externally true.
