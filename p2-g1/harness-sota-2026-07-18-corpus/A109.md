## Why the zero-finding conclusion satisfies the two-signal rule

Claiming “no precedence ambiguity in the visible set” uses two mechanically independent signals:

1. **Static exhaustive signal:** all 18 unique agent definitions were matrixed against every relevant settings authority surface. This found seven deliberate syntactic overlaps (model, effort, tools, credential deny, permission mode, plugin activation, Task naming), proving the detector can find known-present overlaps rather than always returning zero.
2. **Runtime-semantics signal:** current official Claude Code documentation independently supplies a tie-break for each overlap: model resolution order, effort override, tool allowlisting, deny-before-allow, parent permission-mode precedence, agent-source priority, and Task aliasing. None remains without a defined winner.

A live Windows smoke test would be a stronger third signal, but is unavailable on this Linux node. Thus the conclusion is limited to documented runtime behavior and the supplied bytes; it does not say that the Windows installation is healthy, that all hooks fire, or that the nine unavailable agents are coherent.

## Minimal-edit disposition

There is no confirmed precedence conflict, so the minimal safe edit is **no edit**. In particular:

- Do not copy global model/effort defaults into all agents; doing so would erase deliberate routing and duplicate native precedence.
- Do not add every agent tool to `permissions.allow`; omission is not denial, and doing so would broaden silent execution.
- Do not rename the user `codex` agent merely because the Codex plugin is enabled; plugin scoping and source priority already resolve this.
- Do not add prose attempting to override permission enforcement; official docs state that model instructions shape attempts but do not change what Claude Code allows ([official permissions docs](https://code.claude.com/docs/en/permissions.md), lines 41-45).

This disposition rides the native host bus, introduces no second runtime, database, critic, SaaS, or guardrail framework, and therefore passes the anti-overfit gate by adding zero architecture.
