2. `/python-review` promises a prose report that can block, while `python-reviewer` requires a

Code's current runtime contract, under which a custom agent body is its system prompt and its final
message returns verbatim to the parent. The remaining 1-10% is because the remote snapshot cannot

restart Claude Code (agents load at session start), invoke each command in a disposable repository,

### Runtime precedence verified from the native contract

This is not inferred from file order. Current official Claude Code documentation says:

* a legacy `.claude/commands/<name>.md` file and a skill create the same prompt-based command
  mechanism; bundled skills give Claude instructions and let it orchestrate the work
  ([Extend Claude with skills](https://code.claude.com/docs/en/slash-commands));
* a filesystem custom agent's Markdown body becomes that subagent's **system prompt**, and the
  fresh agent separately receives the parent's delegation task message
  ([Create custom subagents](https://code.claude.com/docs/en/sub-agents)); and
* the parent receives the subagent's final message verbatim as the Agent tool result
  ([Subagents in the SDK](https://code.claude.com/docs/en/agent-sdk/subagents)).

Accordingly, once a named custom agent is actually selected, its imperative system-prompt
constraint wins over contradictory task text derived from the command. The parent may later
summarize that tool result, but it cannot make the agent's *own* final message have the command's
forbidden format. This runtime winner is **almost certain (90-99%)** given the native message
construction documented above and the local use of ordinary filesystem agent definitions. Exact
behavior of the owner's installed build is **UNVERIFIED; experiment:** the disposable interactive
trace described in the executive result settles the residual version/configuration risk.

The corpus confirms these custom definitions are real runtime capabilities rather than unused
fiction: `capability_use.agents_invoked` records `code-reviewer=29`, `planner=28`,
