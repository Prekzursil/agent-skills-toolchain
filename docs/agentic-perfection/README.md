# docs/agentic-perfection/

The durable record of the *agentic-perfection / proactive-partner* program — the
work that makes the agent reliable, proactive, human-like, and AGI-adjacent by
putting discipline in the **harness** rather than the model's intentions.

## How to revisit (read this first)

If you (or a future session) reference *"the proactive-partner / agentic-perfection
program / that big improvement thing we explored"* — load these files; you do **not**
need to re-articulate the original prompt, the intent + plan are captured here.

| File | What it is |
|------|------------|
| [`CHANGELOG.md`](CHANGELOG.md) | **Start here.** What shipped, each gem + trigger, the dispatcher architecture, durability spine, anticipatory layer, infra fixes, and what's versioned vs deferred. |
| [`AGENTIC-PERFECTION-PLAN.md`](AGENTIC-PERFECTION-PLAN.md) | The full plan: structural diagnosis, Tier 1–3, the 3 exploration rounds (12-lens, 8-lens, wildcard gems), gold-plating-to-skip. |
| [`PROACTIVE-PARTNER-PROGRAM.md`](PROACTIVE-PARTNER-PROGRAM.md) | The session arc + the user's own **unlocking prompts** (preserved faithfully) + the research grounding. The never-forget / prompt-fatigue cure made concrete. |
| [`OPEN-THREADS.md`](OPEN-THREADS.md) | Point-in-time snapshot of the backlog / open loops at capture time. Live state continues in `~/.claude/OPEN-THREADS.md`. |
