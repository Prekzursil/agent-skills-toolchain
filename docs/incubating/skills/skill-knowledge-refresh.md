# skill-knowledge-refresh

## Purpose

Potential future skill for mining repeated lessons from accepted work and refreshing live skill references with derived summaries only.

## Why this is not a live skill yet

- The process belongs in references first, because it is still a supporting maintenance workflow rather than a clearly separate user-facing trigger.
- It needs stronger evidence about which source classes are most reliable and least noisy.

## Likely scope

- inspect recent memory summaries, rollout notes, accepted PRs, and workflow diffs
- normalize repeated lessons into reusable guardrails or prompt patterns
- decide whether a lesson belongs in a live reference or stays incubating

## Planned resources

- evidence classification rubric
- update template for derived notes
- promotion rules for moving an incubation lesson into a live skill
