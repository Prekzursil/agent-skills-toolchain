The **canonical** GRACE Track-1 pipeline is the Kaggle notebook `FINAL/notebook94c050a41f.ipynb`, NOT the `grace/` BIO-tagger package (that was an earlier dead-end). Approach differs completely:

**Recipe (sentence-level 4-class):** each sentence/annotated-span → None/Premise/Claim/MajorClaim. Encoding `prev_sentence [SEP] sentence`, max_len 192, spaCy `es_core_news_sm` segmentation. Differential LR (body 1e-5, head 1e-4), AdamW wd 0.05, cosine + warmup 100, weighted CE with **MajorClaim weight=10**, batch 16, 15 epochs, EarlyStopping patience 4, fp16. Real-time strict-F1 dev scoring each epoch + **0.50 MajorClaim prob override**. `label_smoothing_factor=0.15` is set but INERT (custom compute_loss uses plain F.cross_entropy). Two-stage "Auto-Runner": Phase 1 train→dev find best epoch; Phase 2 full-fit train+dev for best+1, save blind logits/epoch.

**Data:** 350 train / 50 dev docs (Premise 1536/218, Claim 666/99, MajorClaim 64/**9 in dev** → MajorClaim F1 swings wildly seed-to-seed; always report mean±std, not best-seed). Blind test 2474 docs.

**Per-model overrides (NOT a string swap):** ModernBERT (BSC-LT/MrBERT-biomed, MrBERT-es) need `attn_implementation="eager"`; mDeBERTa-v3 NaNs under fp16 → fp16 OFF (fp32 on Kaggle; no bf16 on T4/P100). Always `ignore_mismatched_sizes=True`. ModernBERT needs transformers>=4.48.

**Kaggle API access:** CLI authenticates via `KAGGLE_API_TOKEN` env var (KGAT_ access-token format) — user `prekzursil`. Data is a Kaggle dataset `alexcristea72/iberlef-grace` (attach via dataset_sources; mounts under /kaggle/input/**, auto-glob to find files). Push kernels with `kaggle kernels push -p <dir>` (needs kernel-metadata.json: kernel_type=script, enable_gpu+enable_internet=true). **Gotchas:** (1) max **2 concurrent GPU sessions** → sweeps run in waves of 2; (2) the `kernels status` / GetKernelSessionStatus endpoint returns server-side **500** — unusable; use `kaggle kernels output <user>/<slug> -p <dir>` as the completion signal (returns /kaggle/working files only once a version finishes). Persistence is files-only by default for headless pushes.

**Sweep harness:** `FINAL/kaggle_runs/gen_kernels.py` generates per-(model,seed) kernels (one config each) with all overrides baked in; `orchestrate.py` runs the whole queue autonomously (cap-aware, retries flakiness, live per-epoch progress, artifact collection to `outputs_final/<slug>/`); `live_monitor.sh`/`poll_wave.sh` for ad-hoc watching. Artifacts per run: dev_logits.npy, dev_predictions.json (GRACE format), metrics.csv, metrics.json (per-epoch per-class P/R/F1), epochN_blind_logits.npy, log.txt. See [[grace_session_handoff_2026-04-09]] for the older BIO experiments.

**CRITICAL Kaggle gotchas (2026-06, hard-won):**
1. **P100 hangs forever** — Kaggle base image = torch 2.10+cu128, which DROPPED Pascal sm_60. API assigns P100 by default; `cuda.is_available()` is True but the first real compute kernel HANGS (3h+, no error). **Fix: force T4** via `machine_shape: "NvidiaTeslaT4"` (sm_75, supported). Valid values: NvidiaTeslaT4 / NvidiaTeslaP100. ALWAYS add a fail-fast GPU guard (`torch.randn(8,8).cuda()@... ` in try/except → SystemExit) so a P100 fallback dies in seconds, not hours.
2. **machine_shape breaks CREATE** (404 "Notebook not found") — only works on UPDATE. So: create kernel minimal (CPU, init.py, no machine_shape/dataset) → THEN update to full GPU+T4+dataset. `push_job.sh` does this 2-step.
3. **Wedged slugs/titles** — a failed/cap-rejected create leaves a ghost; reusing that slug→"Notebook not found", reusing the title→409 Conflict. Use FRESH short slugs+titles (e.g. `gt1-<short>-s<seed>`).
4. **Caps**: 2 concurrent GPU sessions, 5 concurrent CPU sessions. Cancel a stuck/queued kernel by pushing a trivial CPU version (supersedes the run, frees the slot).
5. **Output is live-streamable** — `kaggle kernels output <user>/<slug> -p <dir>` returns a growing snapshot of /kaggle/working while running (poll every ~35-40s). The `kernels status` endpoint 500s server-side — don't use it. Tee class MUST implement `isatty()`/`__getattr__` (latest transformers calls sys.stdout.isatty()).
6. **mDeBERTa-v3 NaNs**: grad_norm=nan from step 1 even in fp32 on torch 2.10 → collapses to all-None (0 F1). Fix attempt: pin `transformers==4.46.3` for that kernel (others need >=4.48 for ModernBERT).
