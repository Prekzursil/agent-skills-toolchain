A unified PySide6 desktop GUI for the Battle Cats RE toolkit. **P1 (the shell) is built + merged to `origin/main` of `Prekzursil/battlecats-toolkit`** (commit `3993d95`, 2026-05-27): 23-task plan, 105 tests, 99% coverage, Codex-reviewed. Lives at `tools/trainer-gui/` in that repo.

**Stack/decisions:** PySide6 (Qt6, LGPL — chosen over CustomTkinter/Tauri), activity-bar shell (VS Code pattern), graphite-indigo hand-rolled QSS theme, Pydantic settings. 3-layer architecture: existing CLIs stay the **untouched service backend** (`dat-cache-decode/push_event0.py`, `bc_stage_unlock.py`, `bc_event_index.py`, BCSFE, `bc_battle_trainer_mod.py`), thin Qt controllers wrap them, views are pure presentation.

**THE KEYSTONE (every P2-P7 controller copies it — `tools/trainer-gui/trainer_gui/controllers/base.py`):** `BaseController` runs work in a `QThread` `Worker`; subclasses implement `_work(emit_log, is_cancelled) -> (ok, detail, payload)` that runs on the worker thread and **never touches `self`** (results travel via payload); `_apply_payload(payload)` updates state/emits on the GUI thread; `opFinished` fires from `thread.finished` (re-entrancy guard holds until the thread truly stops); `shutdown()` cancels+quits+joins (called from `MainWindow.closeEvent`). `PingController` is the copy-me template. Subprocess-backed checks use SHORT timeouts (adb=3s) so cancel is responsive within the shutdown wait window.

**Run it:** `cd <repo>/tools/trainer-gui && .\.venv\Scripts\python app.py` (or the PyInstaller exe `dist\BattleCatsTrainer.exe`, spec at `bc_trainer_gui.spec`). Tests: `.\.venv\Scripts\python -m pytest`.

**⭐ AXIS GOTCHA (high-value, real-data-validated) — `SaveReader.crown_grid` is TIER-MAJOR `[tier][stage]`** (mirrors BCSFE `chapters[map].chapters[crown_tier].stages[stage]`; real shape = **4 crown tiers × up-to-30 stages**: behemoth 4×30, collab 4×30, zero/dojo 4×12, verified on `SAVE_DATA_stock_20260530_0351.bin`). The spec renders **columns = crown tiers**, so `StagesPanel.grid_model()` **TRANSPOSES** to rows=stages / cols=crown-tiers (`cells[stage][tier]`, `num_stages=len(grid[0])`, tier≥len→`NOT_A_VALID_TIER`). A NON-transposing version (the gate-passed plan literally said "do NOT transpose") **passed 100% line+branch coverage AND 8 review agents** — because all 7 spec tests used 1×1/empty `crown_grid`s, which are **transpose-invariant**. Only a non-square realistic fixture (4×3) exposes it (old code → 4 tier-rows truncating 30 stages to 4 cols, mislabeling stages as crowns). **LESSON: for any matrix/shape logic, include a non-square realistically-shaped fixture; 100% coverage proves lines RAN, never that the SHAPE is right.** [[feedback_full_rigor]]
