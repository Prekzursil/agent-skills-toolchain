# RFC: catalog-class-discovery-only

We propose a new workflow named catalog-class-discovery-only.

Proposed workflow: catalog-class-discovery-only

1. Load the catalog-class registry
2. Emit discovery-only hatch rows
3. Skip mutation of live trees

Acceptance: the known fixture wf.catalog-class.discovery-only is recovered

This is a missing capability. Ship this workflow.
