# Meta-review lens output (stand-in) quoting the overclaim class

The SYN-0015 extractor must treat the next three wrappers as MENTION.
A substring matcher that ignores wrappers will mis-read them as USE.

Quoted example: "every unit passes"

> every unit passes

```
every unit passes
```

The wrappers above are load-bearing. This document does not assert the
quoted class in the reviewer's own voice.
