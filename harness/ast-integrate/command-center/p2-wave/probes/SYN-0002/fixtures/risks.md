# Residual risks (SYN-0002 fixture ledger)

Accepted residual risks that MUST attach to a cause node. An unattached
id here is an orphaned-risk finding.

- RISK-R1: operators may still want a live overlay; accepted only if a Stop-hook exists.
- RISK-R2: a detector-control fixture can itself rot; accepted if named probes re-run on every measure.
