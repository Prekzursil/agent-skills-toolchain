ADV-0138 use-vs-mention control.
The owner mentions marketplace / release mode and explicitly defers the
decision. A keyword matcher that treats mention as decision will
mis-classify this as OWNER-STATED. Semantic matching must not.

OU-DEFER topic=release-mode speech_act=defer value=
Owner: Marketplace publishing and release mode came up; I am not deciding that today — defer it.

BD-MENTION topic=release-mode speech_act=none value=PUBLIC-MARKETPLACE
Program: Release mode is PUBLIC MARKETPLACE (binding).
