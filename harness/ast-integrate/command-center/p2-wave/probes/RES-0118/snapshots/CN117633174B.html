Abstract

The invention relates to the technical field of large model conversations, and particularly discloses a voting consensus system based on a plurality of large model conversations, which comprises the following steps of S1: constructing a model, namely constructing a plurality of groups of LLM large language models, and S2: the user asks questions, the questions are transmitted to all built LLM big language models, and each LLM big language model replies to the user questions, S3: model reply scoring, wherein each LLM big language model transmits each reply to other LLM big language models except the model reply scoring, and the opposite side is required to score the replies, S4: the method comprises the steps of replying a user, obtaining the highest-score reply as a final reply and feeding the final reply back to the user, wherein at least three groups or more than three groups of LLM large language models are built, and the voting consensus system based on the conversation of the plurality of large models can effectively reduce the possibility of answering questions and the eighth way of a main praise by artificial intelligence by setting a mode of consensus among the plurality of LLM large language models, thereby improving user experience.

Description

Voting consensus system based on multiple large model conversations
Technical Field
The invention relates to the technical field of large model conversations, in particular to a voting consensus system based on a plurality of large model conversations.
Background
The large model is short for a large-scale language model, is trained to understand and generate human language, and with the rapid development of artificial intelligence technology, large model dialogue becomes one of research hotspots in the field of natural language processing, and the large model dialogue refers to a model based on deep learning, so that the model can generate natural language replies with semantic and logical consistency by training massive dialogue data.
The artificial intelligence is based on big data statistics and generates information according to probability, which also leads to the situation that the artificial intelligence can not avoid answering questions when replying users, even possibly has a praise eight way, affecting user experience, and needs to improve the situation, so that a voting consensus system based on a plurality of big model dialogs is provided.
Disclosure of Invention
The invention aims to solve the technical problem of providing a voting consensus system based on a plurality of large model dialogues, which can reduce the possibility of answering questions with artificial intelligence and a main channel of a speech, and promote user experience.
In order to achieve the above purpose, the present invention adopts the following technical scheme: a voting consensus system based on a plurality of large model dialogues, comprising the steps of:
s1: constructing a model, and constructing a plurality of groups of LLM large language models (model A and model B. The model N);
S2: the user asks questions, the questions are transmitted to all built LLM big language models, and each LLM big language model replies to the user questions;
S3: model reply scoring, wherein each LLM big language model transmits each reply to other LLM big language models except the model reply scoring, and the opposite side is required to score the replies;
S4: the user is replied, and the reply with the highest score is obtained and fed back to the user as a final reply;
The scoring logic specifically comprises:
(1) The scoring score of the model A on the reply of the user problem is 100, the replies of the model A are respectively transmitted to the model B and the model C, the scoring scores of the model B and the model C on the reply of the model A are 75 and 90, and the comprehensive score is 100+75+90=265;
(2) The scoring score of the model B on the reply of the user problem is 60, the replies of the model B are respectively transmitted to the model A and the model C, the scoring scores of the replies of the model A and the model C on the model B are 100 and 95, and the comprehensive score is 60+100+95=255;
(3) The scoring score of the model C on the reply of the user problem is 80, the replies of the model C are respectively transmitted to the model A and the model B, the scoring scores of the replies of the model A and the model B on the model C are 80 and 100, and the comprehensive score is 80+80+100=260;
And obtaining the reply of the highest score according to the multiple groups of comprehensive scores as a final reply to be fed back to the user.
Preferably, in the step S1, three or more groups of LLM large language models are built.
Preferably, in the step S1, LLM large language model is not strictly required, and can be set as Baichuan-7B and ChatGLM2-6B of an open source.
Preferably, in said S3, when the reply to the user question by the large model does not support scoring, the large model reply is required to confirm the reply.
Preferably, the approval reply is set as three reply modes of "very approval, approval and disapproval".
Preferably, the weight scores of the occurrences of "very approval, disapproval" are counted, and the "very approval=2, approval=1, disapproval= -1" are fed back to the questioning user as the final reply of the final highest score.
In summary, compared with the prior art, the invention has the following beneficial effects:
the invention can improve the accuracy of voting on the user questions by setting a plurality of LLM big language models to achieve consensus, thereby solving the problems of a large number of errors and misunderstandings contained in the traditional question-answering system, the possibility of answering questions and a main channel of a praise can be effectively reduced, and the user experience is improved by providing high-quality products so as to enhance the user viscosity.
The invention refers to an LLM large language model, which can improve the credibility of voting on the user problem, help the human to do more things, improve the working efficiency and reduce the cost of the manual productivity.

Detailed Description
The following description of the embodiments of the present invention will be made clearly and completely with reference to the accompanying drawings, in which it is apparent that the embodiments described are only some embodiments of the present invention, but not all embodiments. All other embodiments, which can be made by those skilled in the art based on the embodiments of the invention without making any inventive effort, are intended to be within the scope of the invention.
Referring to fig. 1-3, the present invention provides a technical solution: a voting consensus system based on a plurality of large model dialogues, comprising the steps of:
s1: constructing a model, and constructing a plurality of groups of LLM large language models (model A and model B. The model N);
S2: the user asks questions, the questions are transmitted to all built LLM big language models, and each LLM big language model replies to the user questions;
S3: model reply scoring, wherein each LLM big language model transmits each reply to other LLM big language models except the model reply scoring, and the opposite side is required to score the replies;
S4: and replying the user, and acquiring the reply with the highest score as a final reply and feeding back to the user.
In the step S1, three or more LLM large language models are built.
In the S1, LLM large language model is not strictly required, and can be set as Baichuan-7B and ChatGLM2-6B of an open source.
In said S3, when the reply to the user question by the large model does not support scoring, the large model reply is required to confirm the reply.
The approval reply is set as three reply modes of "very approval, approval and disapproval".
The weight scores of the occurrences of "very approval, disapproval" are counted, and the "very approval=2, approval=1, disapproval= -1" is fed back to the questioning user as the final reply with the reply of the final highest score.
Working principle:
Before use, three or more LLM large language models (model A, model B. Model N) are built, such as Baichuan-7B, chatGLM2-6B and the like which are open sources, and the specific models do not have strict requirements;
When the method is used, a user inputs a language or text through a terminal to ask questions, the question input mode does not have specific requirements, the method can be a multi-mode input mode, the questions are transmitted to all built LLM big language models after asking the questions by the user, each LLM big language model replies the questions of the user, each reply is transmitted to other LLM big language models except the user after replying, the opposite side is required to score the replies, and model A, model B and model C are set to score the replies to the questions of the user:
(1) The scoring score of the model A on the reply of the user problem is 100, the replies of the model A are respectively transmitted to the model B and the model C, the scoring scores of the model B and the model C on the reply of the model A are 75 and 90, and the comprehensive score is 100+75+90=265;
(2) The scoring score of the model B on the reply of the user problem is 60, the replies of the model B are respectively transmitted to the model A and the model C, the scoring scores of the replies of the model A and the model C on the model B are 100 and 95, and the comprehensive score is 60+100+95=255;
(3) The scoring score of the model C on the reply of the user problem is 80, the replies of the model C are respectively transmitted to the model A and the model B, the scoring scores of the replies of the model A and the model B on the model C are 80 and 100, and the comprehensive score is 80+80+100=260;
And obtaining the reply of the highest score according to the multiple groups of comprehensive scores as a final reply to be fed back to the user.
When the reply of the large model does not support scoring, whether the large model reply approves the reply is required, the approval reply is set as three reply modes of 'very approval, approval and disapproval', the weight score of 'very approval, approval and disapproval' is counted to be 'very approval=2, approval=1 and disapproval= -1', and the reply with the highest final score is used as the final reply to be fed back to the questioning user;
Through the mode of setting up a plurality of LLM big language models and reaching the consensus, can effectively reduce the possibility that artificial intelligence answer questions and a main praise and congratulation eight ways, promote user experience.
