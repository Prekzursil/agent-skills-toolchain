# skill.council

Four-voice prompt skill. This body is NOT part of the always-resident
index. The gateway loads these bytes only after Gateway.activate("skill.council").

## Roles (static sections)

1. Architect — structure, interfaces, invariants.
2. Skeptic — missing controls, overclaim, both-states gaps.
3. Pragmatist — what this tree can actually run.
4. Critic — residual risk after the other three.

## Instructions

Invoke the four named roles as static prompt sections. No executable
policy. No CouncilSpec expression tree. No runtime stopping predicate.

## Why this body exists

A4's claim is that the index record (id, kind, tags, summary) is enough
to SELECT this skill, and that the full instructions stay on disk until
activation. Deactivation is unload-context: the session drops these
bytes and they are no longer counted in resident context.

Padding so always-on vs floor is a measured byte delta, not a rounding
error: the catalogue-class skill surface is larger than a tag list.
