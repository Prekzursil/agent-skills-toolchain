* `cross-vendor-dispatch.md:7-17` bans backgrounding a work-unit dispatch.
* `AGENTS.md:41-47` requires every long Codex generation and multi-agent dispatch to use `longrun` with `run_in_background`/`Monitor`, never a blocking foreground call.

The coherent invariant is: **a fan-in dependency must not be released until the child has reached a terminal state and the contracted output has passed verification**. Whether the child OS process is foreground or supervised in the background is an implementation detail. This distinction preserves AGENTS §4a and the incident lesson without forcing a second orchestration runtime.

## Collision register

### C01 — Foreground work-unit mandate versus higher-precedence background mandate

**Class:** CONTRADICTION  
**Artifacts:**

* `claude/rules/common/cross-vendor-dispatch.md:7-17`: “A work-unit dispatch MUST block”; bans `--background`, `&`, `nohup`, detached spawn, and `run_in_background` when a barrier awaits the result.
* `claude/AGENTS.md:41-47`: every operation expected to exceed 60 seconds, explicitly including long Codex generations and multi-agent dispatch, “MUST run via `longrun` with `run_in_background`/`Monitor` — never a blocking foreground call.”

**Precedence:** AGENTS §10 resolves this in favor of `AGENTS.md`: it is the level-3 cross-tool behavior contract (`AGENTS.md:121-127`). The target rule has no assigned precedence and cannot silently override level 3. The collision is not resolved semantically, however: blindly applying AGENTS permits exactly the early-return behavior the target incident is trying to prevent.

**Diagnosis:** badly written boundary. “Block” conflates a foreground OS child with a closed fan-in barrier. A supervised background process can still be synchronously awaited at the work-unit abstraction; a foreground process can still sever its result stream and falsely release the barrier.

**Resolution — NATIVE (Claude Code already does this; we just enable it):** rewrite the target invariant as “the work-unit adapter MUST NOT return to its fan-in caller until terminal evidence is verified.” Keep AGENTS §4a process supervision. Explicitly permit `longrun`/Monitor internally, but forbid returning a job receipt as the work-unit result. The existing synchronous `codex` agent already describes that abstraction at `agents/codex.md:2-15,63-71,87-104`; route work units through it.

Confidence: **almost certain (90-99%)**, from the direct modal verbs in the two files and the explicit precedence list.
