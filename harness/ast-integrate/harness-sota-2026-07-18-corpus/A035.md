### Concrete collision

A Claude work-unit invokes Codex to perform a substantive task expected to take five minutes, and a fan-in barrier requires Codex's result before synthesis. The contract explicitly classifies both “long Codex generations” and “multi-agent dispatch” as operations that **MUST** use `run_in_background`/`Monitor` and must **never** be blocking foreground calls. The rule explicitly classifies the same result-bearing dispatch as one that **MUST block** and **NEVER** use `run_in_background`. Both texts apply before the one launch, and one cannot choose a launch mode satisfying both absolutes.

This is not hypothetical capability plumbing: `corpus.json` records 47 calls to `mcp__codex__codex`, five to `mcp__codex__codex-reply`, three `codex:codex-rescue` agent invocations, and one `codex` agent invocation (`capability_use.mcp_tools_used` and `capability_use.agents_invoked`). ### Which wins at runtime
