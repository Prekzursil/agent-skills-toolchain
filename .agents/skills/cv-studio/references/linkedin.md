# LinkedIn profile optimisation (2026)

Recruiter surfacing on LinkedIn is **keyword search** (LinkedIn Recruiter ranks on profile
keyword hits) — the same mechanism as an ATS. So keyword-rich text in the searched fields is the
single biggest lever (very likely, 80-90%). Generate `linkedin.md`; do NOT auto-write the live
profile (ToS — defer to the D-stream LinkedIn MCP, consent-gated).

## Headline (≤220 chars — use them all)
- Formula: `Role | Specialisation | Key tools/skills | value proposition`.
- Front-load the exact terms recruiters boolean-search ("Reverse Engineer", "Android Security",
  "Ghidra", "Frida"). The headline is the highest-weighted searched field.
- "Open to Work" as **text** in the headline reaches recruiters who filter on words, not just the
  green #OpenToWork frame.
- Example (fictional): `Security Researcher & Reverse Engineer | Android internals, native RE |
  Ghidra · Frida · Qiling · IDA | I ship open tools researchers actually use`.

## About (≤2,600 chars; first ~300 show before "See more")
- Front-load the strongest keyword-rich sentence — most viewers never expand "See more".
- Then: what you do → proof (2-3 quantified wins from `x_master`) → tools (keyword line) → a
  soft call to action. First person, plain, scannable.

## Skills section (drives endorsements AND search)
- Add the exact tools as discrete skills (name "Ghidra", "Frida", "IDA Pro" individually).
- Pin the 3 most search-relevant to the top. Endorsements weakly boost ranking.

## Experience / Featured
- Mirror the CV bullets (XYZ, quantified). Use the **Featured** section to link CVEs, GitHub
  tools, talks — verifiable artifacts.

## Completeness + activity
- "All-Star" completeness and recent activity affect passive-search visibility. A detailed,
  active profile correlates with materially more recruiter interest.

## Honesty on the vendor stats
- **SSI** (Social Selling Index, 0-100) is a *sales* vanity metric (4 pillars: brand, find
  people, engage, relationships). Useful as a self-audit; weak as a recruiter signal.
- "SSI>70 → 45% more opportunities / 51% more likely to hit targets" comes from LinkedIn-sales +
  automation-vendor blogs. Treat as **directional and probably inflated** (confidence the raw
  figures are rigorous: unlikely, ~20-35%). The *mechanism* (keywords → more search hits) is
  sound; the *percentages* are marketing. Don't quote them as fact.

## ToS boundary (read-first)
Automated profile editing / scraping risks LinkedIn ToS and account restriction. Prefer the
official API, read-first, writes consent-gated. This skill only *drafts* text — a human (or the
consent-gated D-stream MCP) applies it.
