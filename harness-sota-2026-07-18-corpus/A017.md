**Why this is badly written rather than merely unenforced.** Even perfect execution of the literal command cannot cover the file population that causes the rule to load. Shell glob behavior and repository layout are external variables; the mismatch is structural before either is considered.

**Specific resolution — BUILD-SMALL (<~200 lines, rides the existing hook/skill/MCP bus).** Replace source-tree globs with the staged C/C++ file list, passed as an argument array to `clang-format`, and run `clang-tidy` using `compile_commands.json` or the project's configured wrapper/preset. A `CMakeLists.txt`-only change should trigger configure/build validation, not an empty `src/*.cpp` analyzer invocation. This is **very likely (80-90%)** to eliminate the documented coverage holes because the evidence is the direct set difference between `:1-10` and `:19-24`; the residual uncertainty is tool availability and each project's generator layout.
