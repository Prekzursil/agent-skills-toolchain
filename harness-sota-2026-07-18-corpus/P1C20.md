# P1C20 — normalized audit findings C17–C20

## Scope and method

This artifact normalizes the 38 finding blocks in `C17.md`, `C18.md`, `C19.md`, and `C20.md`. It does **not** verify the cited paths, command outputs, URLs, runtime state, or recommendations against the subject. Every evidence item below is therefore **UNVERIFIED**; the settling experiment is the later verification phase opening each cited path/range and reproducing each cited bounded command under the original read-only constraints.

`SUPPORTED` means the cited evidence, if accepted at face value, directly entails the normalized claim. `PARTIAL` means it supports a factual core but not a necessity, sufficiency, exclusivity, absence, or design conclusion embedded in the claim. `UNSUPPORTED` would mean the cited evidence does not establish the claim even if accepted; no record met that threshold. These are internal-coherence judgments, not truth judgments.

The confidence attached to each support judgment is **almost certain (90-99%)**, based on a second pass comparing each one-sentence claim with the evidence text printed in the same finding block. The residual uncertainty comes from ambiguous source phrasing and compound claims. No proposal is originated or endorsed by this unit, so NATIVE-vs-BUILD tags do not apply; source proposal tags are retained as `source_tag`. The anti-overfit gate is not invoked because this unit proposes no architecture.

Claimed severity is normalized from each source block's `value x effort` field: `high` or `med` is the source's value/impact claim, not an independently verified severity rating. Duplicate labels are conservative: `DUPLICATE` denotes substantially the same asserted defect, while `RELATED` denotes shared evidence or mechanism without equivalence.
