### Runtime-precedence basis

Claude Code's official subagent documentation states that the frontmatter `tools` field controls subagent capabilities and demonstrates it as an allowlist; omitted tools are unavailable to that subagent. See https://code.claude.com/docs/en/sub-agents, section “Control subagent capabilities.” The official tools reference further says the tool names are the exact strings used in subagent tool lists: https://code.claude.com/docs/en/tools-reference.

Claude Code's official managed-MCP documentation states that an installed `managed-mcp.json` is exclusive: only its servers load, and user-, project-, plugin-, and Claude.ai-provided servers cannot be used. See https://code.claude.com/docs/en/managed-mcp, section “Exclusive control with managed-mcp.json.” The general MCP documentation says plugin MCPs normally start automatically when enabled, but the managed exclusive rule is the higher-precedence exception: https://code.claude.com/docs/en/mcp, sections “Plugin-provided MCP servers” and managed allowlist notes.

These official contracts verify the precedence rules. They do not prove that the particular owner machine loaded a particular agent or server in a particular session. A live Windows probe is still required wherever noted.
