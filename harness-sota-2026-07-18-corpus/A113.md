## Runtime resolution model used

1. A custom agent's `tools` field is an availability allowlist. An agent with `tools: Read, Grep, Glob, Bash` cannot use MCP tools. Source: [Create custom subagents — Available tools](https://code.claude.com/docs/en/sub-agents#available-tools).
2. By default an agent inherits MCP tools available in the main conversation, but an agent may add an `mcpServers` reference or inline definition. None of the 18 supplied agents has an `mcpServers` field. Source: [Create custom subagents — Scope MCP servers to a subagent](https://code.claude.com/docs/en/sub-agents#scope-mcp-servers-to-a-subagent).
3. Duplicate MCP names resolve as a whole server entry, not field-by-field: local scope wins over project, then user, plugin, and claude.ai connector. Source: [Connect Claude Code to tools via MCP — scope hierarchy](https://code.claude.com/docs/en/mcp#scope-hierarchy-and-precedence).
4. Plugin MCP servers connect when their plugin is enabled; disabling a plugin disables that plugin's server but says nothing about a separately configured standalone server of a similar name. Source: [Connect Claude Code to tools via MCP — plugin MCP servers](https://code.claude.com/docs/en/mcp#plugin-mcp-servers).
