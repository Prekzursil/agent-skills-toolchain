Therefore the verified architectural runtime result is:

* If only agent A is invoked, A’s text is the applicable custom-agent prompt; agent B’s file is not a competing instruction in that isolated subagent.
* If A and B are both invoked, neither file overrides the other. Both return results to the parent, and the parent must synthesize/surface the disagreement.
* If contradictory clauses are inside the same agent file, the model sees both. Which natural-language clause it follows on a particular run is **UNVERIFIED; settle with repeated live invocations using the synthetic cases below**. There is no documented “later Markdown line always wins” rule, so I do not assert one.

This is the answer to “which wins at runtime”: for every cross-file conflict below, **neither wins by prompt precedence**; the selected agent wins inside its own isolated run, and the parent owns the collision when both are dispatched. The collision is also internal to `code-reviewer.md`: its own later mandatory contract at `:250-260` repeats the specialist adverse-inference and `PLAUSIBLE` requirements.
