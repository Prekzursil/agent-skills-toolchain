# P1C19 — Normalized audit findings C13–C16

## Scope and method

This artifact normalizes the 33 explicitly numbered findings in `C13.md`, `C14.md`, `C15.md`, and `C16.md`. It does **not** verify any citation against the underlying subject. `SUPPORTED` means the cited evidence, taken at face value, supports the stated claim; `PARTIAL` means it supports only part of the claim or the claim extends into an operational, universal-negative, normative, or forward-looking conclusion not established by the citation; `UNSUPPORTED` means the cited evidence does not establish the claim. Assessment confidence uses the mandated confidence bands and is confidence in this internal-coherence judgment, not confidence that the underlying evidence is true.

Stable IDs are source-stable: `P1C19-<file>-<finding>`. “Claimed severity” is normalized from the source's `value x effort` value axis (`high` or `med`), because the source does not provide a separate severity field. This mapping is **very likely (80-90%)** to preserve the intended priority signal: every finding supplies that value axis, while none supplies another severity label (`C13.md:10,18,26,34,42,50,58,66`; `C14.md:12,20,28,36,44,52,60,68`; `C15.md:15,23,31,39,47,55,63,71`; `C16.md:14,22,30,38,46,54,62,70,78`).

No exact duplicates were found. Two overlap pairs are retained because their conclusions differ: `P1C19-C13-F5` ↔ `P1C19-C15-F1` both cite lossy handoff/ledger receipts, while `P1C19-C14-F3` ↔ `P1C19-C15-F8` both propose a small reducer on the existing shared dispatcher bus. It is **almost certain (90-99%)** these are overlaps rather than duplicates because each pair has different triggering semantics and desired outcomes in the source claims.

`NATIVE-vs-BUILD` is supplied only where the normalized claim itself contains a proposal. It classifies the proposal in this artifact, not the source's looser tag vocabulary. No proposal introduces a second orchestration runtime, vector database/knowledge graph, durable-execution engine, trained critic, observability SaaS, or guardrail framework; every classified build rides the existing hook/skill/MCP bus.
